# 技能导入

技能是一个目录，而不只是 Markdown 表单。[Agent Skills 格式规范](https://agentskills.io/specification)要求目录包含 `SKILL.md`，并允许附带脚本、参考资料和资源文件。

## 普通用户

在「技能 → 新建技能」选择来源：

- **项目 URL**：HTTPS Git 仓库根地址，可填写分支、标签或提交。私有 GitHub 仓库沿用当前用户已连接的 GitHub 身份，不接受管理员服务凭证。
- **上传文件或压缩包**：支持 `.zip`、`.tar.gz`、`.tgz`、`.tar` 和 `.md`。压缩包可以包含一个或多个技能目录；Markdown 文件会解析 frontmatter 中的名称和描述。
- **手动编写**：保留原有名称、描述、指令表单。

选择个人或有管理权限的共享上下文，先预览，再勾选技能并确认导入。预览显示指令、附件路径和不可导入原因。导入前会重新核对来源指纹、范围权限和同名冲突；来源变化需要重新预览。

导入后的技能归当前用户创建，在目标上下文发布，保留目录内的文本、图片等二进制附件和脚本执行权限。不会注册为组织技能包，也不会自动跟随 Git 更新。已有同名技能（包括已归档记录）不会被覆盖；可以编辑或恢复已有技能。

## 管理员

在管理页面的技能包区域选择「项目 URL」或「上传文件或压缩包」。上传后，通过「浏览技能」预览并选择要分发的技能和目标范围。

上传的原文件保存在现有 Postgres 技能包仓储中，跨实例和重启保留。上传包是固定快照，不显示 Git 自动同步操作；Git 包继续沿用原有同步行为。常规列表和注册响应不会返回原文件内容。

## 格式与限制

- 上传文件最多 **8 MiB**，压缩包最多 **5000 个条目**，解压文件总量最多 **32 MiB**。
- 拒绝路径穿越、绝对路径、重复路径、链接、特殊文件、加密 ZIP 和损坏文件。
- 图片等二进制附件以 base64 保存，加载到运行环境时恢复原始字节，不会因附带图标而阻止整个技能导入。无法读取的附件和不安全路径仍会被拒绝。
- 普通用户导入保留每个技能目录内的附件。需要仓库级共享文件的技能集合，应由管理员通过技能包分发，沿用共享文件物化机制。
- 项目 URL 指 Git 仓库根地址，暂不支持网页目录链接或远程压缩包下载地址。压缩包请直接上传。

导入只保存和发布技能，不执行其中的脚本。模型使用技能的行为需另外通过真实模型验收。
