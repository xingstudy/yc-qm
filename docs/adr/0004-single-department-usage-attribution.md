# 未指定主部门时采用唯一有效部门归属用量

2026-11-06 确认：使用量优先归入有效的显式主部门；用户未指定主部门、但只有一个有效部门关系时，自动采用该部门。多个有效部门且未指定主部门时标记“归属待确认”，没有部门时标记“未分配”，不把同一消耗重复计入多个部门。

相较于要求所有单部门用户额外设置主部门，这减少配置遗漏造成的归属缺失，同时保留多部门成员的明确选择。该决策细化[永久保留与历史归属决策](0001-preserve-usage-and-historical-attribution.md)中的发生时归属选择规则，仍保存发生时部门与层级，不因之后的组织调整自动重写历史；历史更正必须明确确认并保留依据。

自动选择只确定使用量归属，不修改组织主部门或成员关系。有效的归属节点包含部门与团队，组织根节点只承担汇总；归档节点不用于新用量自动归属，但保留其历史统计。
