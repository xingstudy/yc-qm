# 按生效版本估算参考费用并保留历史金额

参考费用用于成本分析，采用供应商官方默认单价或管理员自定义单价，保留 SDK 金额和估算来源，不用于实际扣费或将订阅用量解释为额外付款。价格保存版本与生效时间，改价仅影响生效后的使用量，官方默认更新不覆盖自定义价，历史补估和纠错须另行预览确认。相较于用最新价格动态重算全部历史，这需要保存估算依据与价格版本，但能避免改价导致历史报表无声变化，并保证长期分析可追溯。

2026-10-14 用户确认：新模型补充价格后可执行历史补估。管理员选择记录模型、日期范围与适用价格版本，预览数量、金额和不可补估原因后确认；仅补未知费用，已有 SDK 金额与历史估算保持不变。选定版本可明确用于其生效前的未知记录，但不改变该版本对新调用的生效时间。缺失模型身份、Token 类别或服务条件的记录继续保持未知。补估保留原费用状态和价格快照；预览固定记录集合，确认时发现记录变化则要求重新预览，重复确认不重复计入金额。
